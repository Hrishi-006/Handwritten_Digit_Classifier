# Handwritten_Digit_Classifier

Self project for handwritten digit classification using Tensorflow.

Sourced and prepared the MNIST dataset from Keras, including data normalization and image reshaping for model compatibility.
Constructed a sequential neural network using the TensorFlow Keras API, incorporating a single dense layer with a Softmax activation function for multi-class classification.
Trained the model over 50 epochs using the Adam optimizer and sparse categorical cross-entropy loss function.
Results & Impact:
Successfully validated the model's performance, achieving a final accuracy of 91.54 on unseen test data.
Gained practical experience in the full machine learning workflow, from data preparation and model architecture design to training, evaluation, and hyperparameter tuning
